CSS Display — Coba Sendiri

Klik tombol untuk melihat langsung efek setiap nilai display pada elemen

1. Nilai dasar

Mengatur bagaimana elemen itu sendiri berbaris di antara elemen lain.

.kotak { display: block; }

Ini teks sebelum Kotak A lalu ada Kotak B kemudian Kotak C dan ini teks setelah kotak-kotak.

Klik salah satu kotak untuk menyembunyikannya (display: none). Klik lagi tombol "none" untuk menampilkan semua.

2. Flexbox & Grid

Mengatur bagaimana elemen menata anak-anaknya, sekaligus bagaimana elemen itu sendiri berbaris (seperti block/inline).

.kontainer { display: flex; }

Teks sebelum kontainer 1234 lalu teks setelah kontainer.

3. Nilai lainnya (referensi)

Lebih jarang dipakai, tapi tetap bagian dari display.

list-item

Membuat elemen berperilaku seperti item <li>, lengkap dengan bullet/nomor di depannya.

table  table-row  table-cell

Membuat elemen biasa berperilaku seperti <table>, <tr>, <td> tanpa perlu tag tabel asli.

contents

Elemen "dihilangkan" secara visual, tapi anak-anaknya tetap tampil seolah langsung berada di dalam parent-nya.

flow-root

Berlaku seperti block, tapi juga membungkus float/margin anaknya sendiri agar tidak bocor ke elemen luar.

Selain nilai tata letak di atas, display juga menerima nilai global seperti inherit (ikut nilai parent), initial (kembali ke default), unset, dan revert — ini berlaku untuk semua properti CSS, bukan cuma display.
