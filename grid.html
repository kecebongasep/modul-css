Jenis-jenis Grid

Klik tombol pada tiap bagian untuk melihat langsung efeknya

Properti Kontainer

Diatur pada elemen display: grid itu sendiri: grid-template-columns/rows, gap, justify/align-items, justify/align-content.

Properti Item

Diatur pada anak-anak di dalam kontainer grid: grid-column, grid-row (untuk menggabungkan beberapa sel).

1. grid-template-columns

Menentukan jumlah & lebar kolom grid.

.kontainer { grid-template-columns: ; }
