Modul 02

CSS Selector

Pelajari berbagai jenis selector CSS untuk memilih elemen HTML yang ingin diberi style: element selector, class, ID, universal selector, grouping selector, descendant selector, child selector, dan attribute selector.

Tujuan pembelajaran

  • Memahami fungsi selector dalam CSS.
  • Membedakan element selector, class selector, dan ID selector.
  • Menggunakan universal selector untuk memilih semua elemen.
  • Menggabungkan beberapa selector dengan grouping selector.
  • Memilih elemen berdasarkan hubungan parent-child.
  • Memilih elemen berdasarkan atribut HTML.

Konsep dasar: selector untuk memilih elemen

Apa itu CSS Selector?

CSS selector adalah pola atau penanda yang digunakan untuk memilih elemen HTML yang ingin diberi style.

Tanpa selector, CSS tidak tahu elemen mana yang harus diubah. Selector bisa memilih berdasarkan nama tag, class, id, atribut, atau posisi elemen di dalam struktur HTML.

Kenapa selector penting?

Selector membantu kita:

  • Menargetkan elemen: style hanya diterapkan pada bagian tertentu.
  • Menghindari pengulangan: satu aturan bisa dipakai banyak elemen.
  • Membuat desain konsisten: class dapat dipakai ulang.
  • Mengontrol struktur: pilih elemen berdasarkan hubungan di HTML.

Contoh dasar CSS Selector

/* Element selector */
p {
  color: gray;
}

/* Class selector */
.card {
  padding: 16px;
}

/* ID selector */
#judul {
  color: blue;
}

Catatan: selector yang tepat membuat CSS lebih rapi. Gunakan class untuk style yang dipakai berulang, dan gunakan ID untuk elemen yang benar-benar unik.

Penjelasan lengkap selector penting

Element

Element selector

Element selector memilih semua elemen berdasarkan nama tag HTML, misalnya semua p, semua h1, atau semua button.

p {
  color: #475569;
}
Class

Class selector

Class selector memilih elemen berdasarkan atribut class. Ditulis dengan tanda titik .. Class dapat digunakan oleh banyak elemen.

.penting {
  color: red;
  font-weight: bold;
}
ID

ID selector

ID selector memilih elemen berdasarkan atribut id. Ditulis dengan tanda pagar #. ID sebaiknya unik dalam satu halaman.

#judul-utama {
  font-size: 40px;
}
Semua

Universal selector

Universal selector memakai tanda * untuk memilih semua elemen. Sering dipakai untuk reset dasar seperti box-sizing.

* {
  box-sizing: border-box;
}
Grouping

Grouping selector

Grouping selector menggabungkan beberapa selector dengan koma agar memiliki style yang sama.

h1, h2, h3 {
  color: navy;
}
Descendant

Descendant selector

Descendant selector memilih elemen yang berada di dalam elemen lain, tidak harus anak langsung. Ditulis dengan spasi.

.artikel p {
  line-height: 1.6;
}
Child

Child selector

Child selector memilih elemen anak langsung dari parent. Ditulis dengan tanda >.

nav > a {
  margin-right: 12px;
}
Attribute

Attribute selector

Attribute selector memilih elemen berdasarkan atribut tertentu, misalnya input dengan tipe email atau link yang membuka tab baru.

input[type="email"] {
  border-color: blue;
}

a[target="_blank"] {
  color: orange;
}

Peta konsep CSS Selector

Selector dasar: element, class ., dan ID #
Selector luas: universal * dan grouping dengan koma
Selector hubungan: descendant dengan spasi dan child dengan >
Selector atribut: memilih elemen berdasarkan atribut seperti [type="email"]

  4. Menggunakan minimal satu ID selector.

  8. Menggunakan child selector.
