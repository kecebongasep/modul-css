Modul 04

Typography

Pelajari cara mengatur tampilan teks dengan CSS memakai font-family, font-size, font-weight, font-style, line-height, text-align, text-decoration, text-transform, dan Google Fonts.

Tujuan pembelajaran

  • Memahami fungsi typography dalam desain web.
  • Mengatur jenis font, ukuran, ketebalan, dan gaya teks.
  • Mengatur jarak baris dan perataan teks.
  • Menggunakan dekorasi dan transformasi teks.
  • Mengenal cara memakai Google Fonts.

Konsep dasar: typography untuk keterbacaan

Apa itu Typography?

Typography adalah pengaturan tampilan teks agar informasi mudah dibaca, nyaman dilihat, dan sesuai dengan karakter desain halaman.

Dalam CSS, typography diatur dengan property seperti font-family, font-size, font-weight, font-style, line-height, dan property teks lainnya.

Kenapa typography penting?

Typography membantu halaman web menjadi:

  • Mudah dibaca: ukuran dan jarak baris nyaman.
  • Terstruktur: judul, subjudul, dan isi mudah dibedakan.
  • Profesional: pilihan font membuat tampilan konsisten.
  • Komunikatif: teks penting dapat diberi penekanan visual.

Contoh dasar Typography

body {
  font-family: Arial, sans-serif;
  font-size: 16px;
  line-height: 1.6;
}

h1 {
  font-size: 40px;
  font-weight: 800;
  text-align: center;
  text-transform: uppercase;
}

Catatan: typography yang baik bukan hanya soal font bagus, tetapi juga ukuran, jarak, dan keterbacaan.

Penjelasan lengkap materi penting

Jenis font

font-family

Menentukan jenis huruf. Biasanya ditulis dengan beberapa font cadangan.

body { font-family: Arial, Helvetica, sans-serif; }
Ukuran

font-size

Mengatur ukuran teks. Satuan umum: px, rem, dan em.

p { font-size: 18px; }
Ketebalan

font-weight

Mengatur tebal tipis huruf, seperti normal, bold, atau angka 400, 700, 800.

h1 { font-weight: 800; }
Gaya

font-style

Mengatur gaya huruf, misalnya normal atau italic.

.miring { font-style: italic; }
Jarak baris

line-height

Mengatur tinggi baris teks agar paragraf tidak terlalu rapat.

p { line-height: 1.7; }
Rata teks

text-align

Mengatur perataan teks: left, center, right, atau justify.

h1 { text-align: center; }
Dekorasi

text-decoration

Memberi atau menghapus dekorasi teks seperti underline, line-through, atau none.

a { text-decoration: none; }
Kapitalisasi

text-transform

Mengubah kapitalisasi teks: uppercase, lowercase, atau capitalize.

.judul { text-transform: uppercase; }
Web font

Google Fonts

Google Fonts menyediakan font online yang bisa dipakai dengan tag <link> lalu diterapkan melalui font-family.

<link href="https://fonts.googleapis.com/css2?family=Poppins" rel="stylesheet">
body { font-family: 'Poppins', sans-serif; }

Peta konsep Typography

Font: font-family, font-size, font-weight, dan font-style
Keterbacaan: line-height membuat paragraf nyaman dibaca
Gaya teks: text-align, text-decoration, dan text-transform
Font eksternal: Google Fonts dihubungkan dengan <link> lalu dipakai di CSS

Tugas: buat halaman artikel typography

Buat satu file bernama modul-04-typography.html dengan ketentuan berikut:

  1. Menggunakan struktur HTML lengkap.
  2. Menggunakan font-family pada body atau elemen utama.
  3. Menggunakan font-size untuk judul dan paragraf.
  4. Menggunakan font-weight dan font-style.
  5. Menggunakan line-height agar paragraf nyaman dibaca.
  6. Menggunakan text-align, text-decoration, dan text-transform.
  7. Mencoba satu Google Fonts dan menerapkannya pada halaman.
Tantangan tambahan: buat dua gaya typography berbeda: satu untuk artikel utama dan satu untuk quote/catatan penting.
