Modul 05

Box Model

Pelajari konsep Box Model di CSS: urutan Content, Padding, Border, dan Margin, serta property penting seperti width, height, padding, margin, border, dan box-sizing.

Tujuan pembelajaran

  • Memahami susunan Box Model: content, padding, border, dan margin.
  • Mengatur ukuran elemen memakai width dan height.
  • Mengatur jarak dalam dengan padding.
  • Mengatur jarak luar dengan margin.
  • Membuat garis tepi dengan border.
  • Memahami pengaruh box-sizing pada ukuran elemen.

Konsep dasar: setiap elemen adalah kotak

Apa itu Box Model?

Box Model adalah konsep CSS yang menjelaskan bahwa setiap elemen HTML dianggap sebagai sebuah kotak.

Kotak tersebut tersusun dari bagian paling dalam sampai luar: content, padding, border, lalu margin.

Urutan Box Model

Content
   ↓
Padding
   ↓
Border
   ↓
Margin

Memahami urutan ini penting agar kita bisa mengatur ukuran, jarak, dan batas elemen dengan tepat.

Contoh dasar Box Model

.box {
  width: 300px;
  height: 120px;
  padding: 20px;
  border: 4px solid #60a5fa;
  margin: 24px;
  box-sizing: border-box;
}

Catatan: padding adalah jarak di dalam border, sedangkan margin adalah jarak di luar border.

Penjelasan lengkap materi penting

Isi

Content

Content adalah bagian utama elemen, berisi teks, gambar, atau elemen lain. Ukuran content dapat diatur dengan width dan height.

.box { width: 300px; height: 120px; }
Lebar

width

Property width mengatur lebar area content elemen. Nilainya bisa memakai px, %, rem, dan satuan lainnya.

.card { width: 320px; }
Tinggi

height

Property height mengatur tinggi elemen. Gunakan dengan bijak karena konten panjang bisa meluap jika tinggi terlalu kecil.

.banner { height: 200px; }
Jarak dalam

padding

Padding adalah jarak antara content dan border. Padding membuat isi elemen tidak menempel pada tepi.

.box { padding: 20px; }
Garis tepi

border

Border adalah garis di sekitar padding dan content. Border biasanya memiliki ukuran, gaya, dan warna.

.box { border: 2px solid #60a5fa; }
Jarak luar

margin

Margin adalah jarak di luar border. Margin digunakan untuk memberi ruang antar elemen.

.box { margin: 24px; }
Ukuran kotak

box-sizing

box-sizing menentukan cara browser menghitung ukuran elemen. Nilai border-box membuat width sudah termasuk padding dan border.

* { box-sizing: border-box; }
Perbandingan

content-box vs border-box

Pada content-box, width hanya menghitung content. Pada border-box, width menghitung content, padding, dan border.

.box { box-sizing: border-box; }

Peta konsep Box Model

Content: isi utama elemen, dikontrol dengan width dan height
Padding: jarak dalam antara content dan border
Border: garis tepi yang membungkus content dan padding
Margin: jarak luar antar elemen
Box sizing: border-box membuat ukuran lebih mudah diprediksi

Praktikum bertahap

Setiap praktikum langsung punya kode, tombol jalankan, output, dan eksperimen.

1

Width dan height

Atur ukuran content elemen memakai width dan height.

Output akan muncul di sini.
Eksperimen

Ubah width menjadi 500px dan height menjadi 80px. Amati perubahan ukuran kotak.

2

Padding dan border

Tambahkan jarak dalam dan garis tepi pada elemen.

Output akan muncul di sini.
Eksperimen

Ubah padding menjadi 4px lalu 40px. Bandingkan jarak isi terhadap border.

3

Margin antar elemen

Gunakan margin untuk memberi jarak luar antar kotak.

Output akan muncul di sini.
Eksperimen

Ubah margin menjadi 0, lalu 40px. Amati jarak antar kotak.

4

Box-sizing border-box

Bandingkan ukuran elemen dengan dan tanpa box-sizing: border-box.

Output akan muncul di sini.
Eksperimen

Tambahkan box-sizing: border-box; ke semua kotak dengan selector *. Amati ukuran elemen menjadi lebih mudah diprediksi.

Tugas: buat halaman demo Box Model

Buat satu file bernama modul-05-box-model.html dengan ketentuan berikut:

  1. Menggunakan struktur HTML lengkap.
  2. Membuat minimal tiga kotak/card berbeda.
  3. Menggunakan width dan height pada minimal satu kotak.
  4. Menggunakan padding untuk mengatur jarak dalam.
  5. Menggunakan margin untuk mengatur jarak antar elemen.
  6. Menggunakan border dengan ukuran, style, dan warna.
  7. Menggunakan box-sizing: border-box.
  8. Menulis keterangan singkat tentang content, padding, border, dan margin.
Tantangan tambahan: buat dua kotak dengan width sama, satu memakai content-box dan satu memakai border-box, lalu jelaskan perbedaannya.
