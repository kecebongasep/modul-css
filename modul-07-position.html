Modul 07

Position

Pelajari property position untuk mengatur letak elemen di halaman: static, relative, absolute, fixed, sticky, serta arah posisi top, right, bottom, dan left.

Tujuan pembelajaran

  • Memahami fungsi property position dalam CSS.
  • Membedakan static, relative, absolute, fixed, dan sticky.
  • Menggunakan top, right, bottom, dan left.
  • Memahami elemen acuan untuk posisi absolute.
  • Membuat navbar sticky dan tombol fixed sederhana.

Konsep dasar: position untuk mengatur letak elemen

Apa itu Position?

Position adalah property CSS untuk mengatur cara elemen ditempatkan di halaman.

Secara default, elemen mengikuti alur normal dokumen. Dengan position, kita bisa menggeser elemen, menempatkannya relatif terhadap parent, membuatnya tetap di layar, atau membuatnya menempel saat scroll.

Kapan memakai position?

Position sering dipakai untuk:

  • Badge atau label: ditempatkan di sudut card.
  • Navbar: menempel di bagian atas saat scroll.
  • Tombol bantuan: tetap muncul di pojok layar.
  • Overlay: elemen di atas gambar atau konten.

Contoh dasar Position

.parent {
  position: relative;
}

.badge {
  position: absolute;
  top: 12px;
  right: 12px;
}

.help {
  position: fixed;
  bottom: 20px;
  right: 20px;
}

Catatan: property top, right, bottom, dan left baru terasa jelas ketika elemen memakai position selain static.

Penjelasan lengkap materi penting

Default

position: static

Nilai default semua elemen. Elemen mengikuti alur normal halaman, dan property top, right, bottom, left tidak berpengaruh.

.box { position: static; }
Geser ringan

position: relative

Elemen tetap berada di alur normal, tetapi bisa digeser dari posisi aslinya memakai top, left, dan lainnya.

.box {
  position: relative;
  top: 10px;
  left: 20px;
}
Di dalam parent

position: absolute

Elemen keluar dari alur normal dan diposisikan terhadap ancestor terdekat yang memiliki position selain static. Biasanya parent diberi position: relative.

.parent { position: relative; }
.badge { position: absolute; top: 8px; right: 8px; }
Tetap layar

position: fixed

Elemen diposisikan terhadap viewport atau layar browser. Saat halaman di-scroll, elemen tetap berada di tempat yang sama.

.chat {
  position: fixed;
  bottom: 20px;
  right: 20px;
}
Menempel

position: sticky

Elemen awalnya mengikuti alur normal, lalu menempel ketika mencapai posisi tertentu saat scroll. Umumnya memakai top.

.nav {
  position: sticky;
  top: 0;
}
Atas

top

Property top mengatur jarak elemen dari sisi atas acuan posisinya.

.box { position: relative; top: 16px; }
Kanan & kiri

right dan left

right mengatur jarak dari sisi kanan, sedangkan left mengatur jarak dari sisi kiri acuan.

.badge { right: 12px; }
.box { left: 20px; }
Bawah

bottom

Property bottom mengatur jarak elemen dari sisi bawah acuan posisinya. Sering dipakai pada tombol fixed.

.help { position: fixed; bottom: 20px; }

Peta konsep Position

Static: posisi default, mengikuti alur normal dokumen
Relative: tetap di alur normal, bisa digeser dari posisi awal
Absolute: keluar dari alur normal, mengikuti parent ber-position
Fixed: tetap pada viewport meskipun halaman di-scroll
Sticky: mengikuti alur normal lalu menempel saat scroll
Arah: top, right, bottom, dan left menentukan jarak posisi
