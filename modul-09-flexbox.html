Modul 09

Flexbox

Pelajari Flexbox untuk membuat layout satu dimensi yang fleksibel memakai display: flex, flex-direction, justify-content, align-items, gap, flex-wrap, flex-grow, flex-shrink, dan flex-basis.

Tujuan pembelajaran

  • Memahami fungsi display: flex untuk layout fleksibel.
  • Mengatur arah item dengan flex-direction.
  • Mengatur perataan horizontal dengan justify-content.
  • Mengatur perataan vertikal dengan align-items.
  • Mengatur jarak dan pembungkusan item dengan gap dan flex-wrap.
  • Memahami flex-grow, flex-shrink, dan flex-basis.

Konsep dasar: Flexbox untuk layout satu dimensi

Apa itu Flexbox?

Flexbox adalah sistem layout CSS untuk menyusun elemen dalam satu arah utama: baris atau kolom.

Flexbox sangat cocok untuk navbar, tombol berjajar, card horizontal, form sederhana, dan layout yang perlu mudah rata tengah.

Kenapa Flexbox penting?

Flexbox membantu membuat layout:

  • Fleksibel: item bisa menyesuaikan ruang.
  • Mudah diratakan: rata tengah horizontal dan vertikal lebih sederhana.
  • Responsif: item bisa wrap ke baris baru.
  • Efisien: banyak layout bisa dibuat dengan sedikit CSS.

Contoh dasar Flexbox

.container {
  display: flex;
  flex-direction: row;
  justify-content: center;
  align-items: center;
  gap: 16px;
  flex-wrap: wrap;
}

Catatan: display: flex dipasang pada parent/container. Elemen anak langsung di dalamnya menjadi flex item.

Penjelasan lengkap materi penting

Aktifkan Flex

display: flex

Membuat sebuah elemen menjadi flex container. Anak langsungnya akan tersusun mengikuti aturan Flexbox.

.container {
  display: flex;
}
Arah

flex-direction

Mengatur arah utama item: row, row-reverse, column, atau column-reverse.

.container {
  flex-direction: row;
}
Main axis

justify-content

Mengatur perataan item pada arah utama, misalnya flex-start, center, space-between, atau space-around.

.container {
  justify-content: space-between;
}
Cross axis

align-items

Mengatur perataan item pada arah silang, misalnya stretch, center, flex-start, atau flex-end.

.container {
  align-items: center;
}
Jarak

gap

Mengatur jarak antar flex item. Lebih rapi daripada memberi margin pada setiap item.

.container {
  gap: 16px;
}
Bungkus

flex-wrap

Mengatur apakah item boleh turun ke baris baru saat ruang tidak cukup. Nilai umum: nowrap dan wrap.

.container {
  flex-wrap: wrap;
}
Tumbuh

flex-grow

Mengatur kemampuan item untuk mengambil ruang kosong yang tersedia.

.item-besar {
  flex-grow: 1;
}
Mengecil

flex-shrink

Mengatur kemampuan item untuk mengecil ketika ruang container terbatas.

.item {
  flex-shrink: 1;
}
Ukuran awal

flex-basis

Menentukan ukuran awal item sebelum ruang kosong dibagikan atau item mengecil.

.item {
  flex-basis: 200px;
}

Peta konsep Flexbox

Container: parent memakai display: flex
Arah utama: flex-direction menentukan row atau column
Perataan: justify-content untuk main axis dan align-items untuk cross axis
Jarak dan wrap: gap memberi jarak, flex-wrap membuat item turun baris
Ukuran item: flex-grow, flex-shrink, dan flex-basis

Tugas: buat halaman layout Flexbox

Buat satu file bernama modul-09-flexbox.html dengan ketentuan berikut:

  1. Menggunakan struktur HTML lengkap.
  2. Membuat container dengan display: flex.
  3. Menggunakan flex-direction minimal satu kali.
  4. Menggunakan justify-content dan align-items.
  5. Menggunakan gap untuk jarak antar item.
  6. Menggunakan flex-wrap agar item bisa turun baris.
  7. Menggunakan flex-grow pada minimal satu item.
  8. Menggunakan flex-shrink dan flex-basis.
  9. Menulis keterangan singkat kapan Flexbox lebih cocok digunakan daripada Grid.
