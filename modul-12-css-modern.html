Modul 12

CSS Modern

Pelajari fitur CSS modern untuk membuat kode lebih fleksibel dan responsif: CSS Variables, :root, fungsi calc(), clamp(), min(), max(), serta pengaturan media dengan object-fit dan aspect-ratio.

Tujuan pembelajaran

  • Memahami fungsi CSS Variables untuk menyimpan nilai style.
  • Menggunakan :root sebagai tempat variable global.
  • Menghitung ukuran dinamis dengan calc().
  • Membuat ukuran responsif dengan clamp(), min(), dan max().
  • Mengatur tampilan gambar/video dengan object-fit.
  • Menjaga rasio elemen dengan aspect-ratio.

Konsep dasar: CSS modern untuk desain fleksibel

Apa itu CSS Modern?

CSS Modern adalah kumpulan fitur CSS yang membantu developer membuat desain lebih konsisten, responsif, dan mudah dirawat.

Contohnya, CSS Variables membuat warna dan ukuran bisa disimpan sebagai nilai reusable, sedangkan fungsi seperti clamp() dan minmax() membantu tampilan menyesuaikan ukuran layar.

Kenapa CSS modern penting?

CSS modern membantu kita:

  • Mengurangi pengulangan: nilai warna/spacing disimpan dalam variable.
  • Membuat desain responsif: ukuran bisa menyesuaikan layar.
  • Menjaga konsistensi: tema warna lebih mudah dikontrol.
  • Mengatur media: gambar/video lebih rapi dan proporsional.

Contoh dasar CSS Modern

:root {
  --primary: #2563eb;
  --space: 16px;
}

.card {
  width: min(100%, 420px);
  padding: var(--space);
  background: var(--primary);
}

h1 {
  font-size: clamp(32px, 6vw, 64px);
}

Catatan: CSS modern membuat style lebih mudah diubah. Jika warna utama disimpan di variable, kamu cukup mengganti satu nilai di :root.

Penjelasan lengkap materi penting

Variable

CSS Variables

CSS Variables menyimpan nilai yang bisa dipakai ulang. Nama variable diawali dengan dua garis: --nama-variable.

:root {
  --warna-utama: #2563eb;
}

button {
  background: var(--warna-utama);
}
Global

:root

:root memilih elemen paling atas dokumen. Biasanya dipakai untuk menyimpan variable global agar bisa digunakan di seluruh halaman.

:root {
  --radius: 12px;
  --spacing: 16px;
}
Hitung

calc()

calc() digunakan untuk menghitung nilai CSS, misalnya menggabungkan persen dan pixel.

.box {
  width: calc(100% - 40px);
}
Responsif

clamp()

clamp() menentukan nilai minimum, nilai ideal, dan nilai maksimum. Sangat cocok untuk typography responsif.

h1 {
  font-size: clamp(32px, 6vw, 64px);
}
Minimum

min()

min() memilih nilai yang paling kecil dari beberapa pilihan. Cocok untuk membatasi ukuran agar tidak terlalu besar.

.card {
  width: min(100%, 480px);
}
Maksimum

max()

max() memilih nilai yang paling besar dari beberapa pilihan. Cocok untuk menjaga ukuran minimal yang aman.

.section {
  padding: max(16px, 4vw);
}
Media

object-fit

object-fit mengatur cara gambar/video mengisi kotaknya. Nilai umum: cover, contain, dan fill.

img {
  width: 300px;
  height: 180px;
  object-fit: cover;
}
Rasio

aspect-ratio

aspect-ratio menjaga perbandingan lebar dan tinggi elemen, misalnya 16:9 untuk video atau 1:1 untuk gambar persegi.

.video {
  aspect-ratio: 16 / 9;
}

Peta konsep CSS Modern

Variable: CSS Variables menyimpan nilai reusable dengan awalan --
Global scope: :root menyimpan variable untuk seluruh halaman
Fungsi ukuran: calc(), clamp(), min(), dan max()
Media modern: object-fit mengatur gambar/video dalam kotak
Rasio: aspect-ratio menjaga bentuk elemen tetap proporsional

Tugas: buat halaman demo CSS Modern

Buat satu file bernama modul-12-css-modern.html dengan ketentuan berikut:

  1. Menggunakan struktur HTML lengkap.
  2. Membuat CSS Variables di dalam :root.
  3. Menggunakan minimal tiga variable dengan var().
  4. Menggunakan calc() untuk menghitung ukuran elemen.
  5. Menggunakan clamp() untuk typography responsif.
  6. Menggunakan min() atau max() untuk ukuran/spacing fleksibel.
  7. Menggunakan object-fit pada gambar.
  8. Menggunakan aspect-ratio pada gambar, video, atau card.
  9. Menulis keterangan singkat manfaat CSS modern yang digunakan.
Tantangan tambahan: buat tema warna sederhana dengan CSS Variables, lalu ubah satu variable utama untuk melihat efeknya ke banyak elemen.
