Modul 14

Shadow & Layering

Pelajari cara memberi kedalaman visual dan mengatur tumpukan elemen di CSS memakai box-shadow, text-shadow, opacity, z-index, serta konsep dasar stacking context.

Tujuan pembelajaran

  • Memahami fungsi box-shadow untuk bayangan kotak.
  • Menggunakan text-shadow untuk bayangan teks.
  • Mengatur transparansi elemen dengan opacity.
  • Mengatur urutan lapisan elemen dengan z-index.
  • Memahami konsep dasar stacking context agar layer tidak membingungkan.

Konsep dasar: bayangan dan lapisan visual

Apa itu Shadow & Layering?

Shadow & Layering adalah teknik CSS untuk memberi kesan kedalaman, fokus, dan urutan tumpukan pada elemen halaman.

Bayangan membuat elemen terlihat terangkat dari background, sedangkan layering mengatur elemen mana yang berada di depan atau di belakang.

Kapan digunakan?

Shadow dan layering sering dipakai untuk:

  • Card: memberi efek elemen terangkat.
  • Modal/dropdown: memastikan elemen muncul di atas konten lain.
  • Hero text: membuat teks lebih terbaca di atas gambar.
  • Overlay: memberi lapisan gelap/transparan di atas gambar.

Contoh dasar Shadow & Layering

.card {
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.18);
}

.hero-title {
  text-shadow: 0 2px 8px rgba(0, 0, 0, 0.5);
}

.modal {
  position: fixed;
  z-index: 10;
  opacity: 0.95;
}

Catatan: z-index bekerja pada elemen yang memiliki position seperti relative, absolute, fixed, atau sticky.

Penjelasan lengkap materi penting

Bayangan kotak

box-shadow

Property box-shadow memberi bayangan pada kotak elemen. Format umum: offset-x, offset-y, blur, spread, dan warna.

.card {
  box-shadow: 0 8px 24px rgba(0,0,0,.18);
}
Bayangan teks

text-shadow

Property text-shadow memberi bayangan pada teks. Berguna untuk membuat teks lebih terbaca di atas background gambar.

h1 {
  text-shadow: 0 2px 8px rgba(0,0,0,.5);
}
Transparansi

opacity

Property opacity mengatur transparansi elemen dari 0 sampai 1. Nilai 0 tidak terlihat, 1 terlihat penuh.

.overlay {
  opacity: 0.75;
}
Lapisan

z-index

z-index mengatur urutan tumpukan elemen. Nilai lebih besar biasanya tampil di depan, tetapi tetap dipengaruhi stacking context.

.modal {
  position: fixed;
  z-index: 100;
}
Acuan

Position dan z-index

z-index biasanya memerlukan elemen ber-position. Tanpa position, z-index sering tidak memberi efek yang diharapkan.

.badge {
  position: absolute;
  z-index: 2;
}
Stacking

Stacking context dasar

Stacking context adalah area tumpukan elemen. Elemen di dalam stacking context dibandingkan terlebih dahulu dengan elemen satu konteksnya.

.parent {
  position: relative;
  z-index: 1;
}
Overlay

Layer transparan

Overlay biasanya memakai position absolute, background transparan, dan z-index untuk membuat lapisan di atas gambar.

.overlay {
  position: absolute;
  inset: 0;
  background: rgba(0,0,0,.45);
}
Hati-hati

Jangan berlebihan

Shadow yang terlalu kuat dan z-index yang terlalu besar bisa membuat desain terlihat berat dan sulit dirawat.

/* Hindari z-index acak terlalu besar */
z-index: 999999;

Peta konsep Shadow & Layering

Shadow: box-shadow untuk kotak dan text-shadow untuk teks
Transparansi: opacity mengatur tingkat terlihatnya elemen
Layer: z-index menentukan urutan depan-belakang
Syarat umum: z-index biasanya bekerja pada elemen dengan position
Stacking context: konteks tumpukan yang memengaruhi perbandingan z-index
