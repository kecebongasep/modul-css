Proyek Akhir

HTML & CSS Website Project

Pilih satu ide proyek, bangun website responsive level sedang, upload ke GitHub Pages, lalu presentasikan hasilnya. Proyek ini menggabungkan seluruh materi HTML dan CSS yang sudah dipelajari.

Target proyek

  • Menerapkan struktur HTML, semantic HTML, media, list, table, dan form.
  • Menggunakan CSS dasar, layout, responsive design, dan efek visual.
  • Membuat website yang rapi, mudah dipakai, dan bisa diakses online.
  • Melatih kemampuan menjelaskan proses pembuatan website.

Materi yang wajib diterapkan

Website final minimal menunjukkan penggunaan materi berikut:

Struktur HTMLText & ContentLink & NavigationImage & MultimediaListTableFormSemantic HTMLCSS SelectorColor & BackgroundTypographyBox ModelDisplayPositionGrid/FlexboxResponsivePseudoAnimationShadow & Layering

Ketentuan umum proyek

Struktur file

  • Folder proyek berisi minimal index.html dan style.css.
  • Boleh menambahkan folder assets/, img/, atau images/.
  • Nama file dan folder rapi, huruf kecil, tanpa spasi.
  • Website dapat dibuka dari index.html.

Minimal konten

  • Minimal 6 section utama.
  • Minimal 1 navigasi responsive.
  • Minimal 1 tabel.
  • Minimal 1 form.
  • Minimal 1 galeri/card list.
  • Minimal 1 gambar dengan alt.

Minimal CSS

  • Menggunakan external CSS.
  • Menggunakan selector element, class, ID, dan pseudo class.
  • Menggunakan Flexbox atau Grid.
  • Menggunakan media query untuk responsive.
  • Menggunakan warna, typography, box model, shadow/layering.
  • Minimal satu transition/animation sederhana.

Level sedang

  • Tidak wajib memakai JavaScript.
  • Desain harus responsive, bukan hanya desktop.
  • Konten harus relevan dengan tema yang dipilih.
  • Website tidak boleh hanya template kosong.
  • Semua link navigasi harus bekerja.

Rubrik penilaian

30% Struktur & Konten

HTML lengkap, semantic, konten sesuai tema, navigasi jelas, form/tabel/list/media digunakan tepat.

30% Desain CSS

Warna, typography, box model, layout, spacing, shadow/layering, dan efek visual rapi.

25% Responsive & Teknis

Tampilan baik di mobile dan desktop, file rapi, GitHub Pages aktif, tidak ada error besar.

15% Presentasi

Mampu menjelaskan ide, struktur kode, fitur utama, responsive design, dan kendala/perbaikan.

Pengumpulan online

Upload via GitHub Pages

Link website wajib bisa dibuka publik.

Langkah pengumpulan

  1. Buat repository GitHub baru, misalnya proyek-akhir-web.
  2. Upload file index.html, style.css, dan folder asset/gambar jika ada.
  3. Buka menu repository: Settings → Pages.
  4. Pada bagian Branch, pilih main dan folder /root, lalu klik Save.
  5. Tunggu sampai GitHub Pages aktif dan menghasilkan link website.
  6. Cek link website di browser/HP. Pastikan semua gambar, CSS, navigasi, dan section muncul.
  7. Kumpulkan link GitHub repository dan link GitHub Pages.
Format pengumpulan:
Nama Lengkap • Kelas/Jurusan • Judul Proyek • Link GitHub Repository • Link GitHub Pages • Catatan singkat fitur utama.

Contoh link: https://username.github.io/proyek-akhir-web/

Presentasi proyek

Demo dan penjelasan website

Durasi ideal 5–7 menit per siswa/kelompok.

Urutan presentasi

  1. Perkenalkan judul dan alasan memilih proyek.
  2. Tunjukkan website dari GitHub Pages.
  3. Jelaskan section utama dan fitur yang dibuat.
  4. Tunjukkan bagian HTML dan CSS yang paling penting.
  5. Jelaskan responsive design dengan simulasi tampilan mobile/desktop.
  6. Ceritakan kendala dan cara menyelesaikannya.

Pertanyaan yang harus siap dijawab

  • Kenapa memilih tema proyek tersebut?
  • Tag semantic HTML apa yang digunakan?
  • Bagian mana yang memakai Flexbox/Grid?
  • Bagaimana cara membuat website responsive?
  • Apa fungsi form/tabel/list/media di websitemu?
  • Apa bagian tersulit saat membuat proyek?

Checklist sebelum submit

  • Website sudah responsive di HP dan laptop.
  • Semua file sudah terupload ke GitHub.
  • GitHub Pages sudah aktif dan link bisa dibuka.
  • CSS terbaca dengan benar.
  • Gambar tampil dan memiliki alt.
  • Navbar, link, form, tabel, dan section utama berfungsi.
  • Siap presentasi dan menjelaskan kode sendiri.
